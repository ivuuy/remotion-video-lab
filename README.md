# 紫晶史莱姆 ASMR

15 秒实拍剪辑预览，1080 × 1920，25 fps。使用连续镜头保留自然揉捏、按压与拉伸节奏，无字幕、无背景音乐。

## 打开预览

双击 `打开预览.command`，或在终端运行：

```sh
./打开预览.command
```

预览地址：http://localhost:3000/SlimeASMR

在 Remotion Studio 中点击播放按钮试听。时间线可调整镜头起点和音量。当前版本保留可编辑工程，未导出最终 MP4。

## 剪辑与声音

- 原片选取：1 秒至 16 秒，保持原速。
- 画面：9:16 裁切，轻微提亮和对比度调整。
- 声音：来自同一素材的同期音轨；90 Hz 高通、8.5 kHz 低通、轻降噪、增益、压缩和限幅，首尾短淡入淡出。
- 未使用合成音效或音乐。
